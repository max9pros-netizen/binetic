Declarative Interface

Write the protocol once in the .tpn DSL. Run it anywhere.

# network.tpn — declare the protocol protocol version 2 { neuron 0x20010DB8000000000000000000000001 phase 500 { threshold 0.43 isa { gate 0 { window 0..100 theta 0.0..1.57 threshold 0.43 route 0 } gate 1 { window 100..200 theta 1.57..3.14 threshold 0.43 route 1 } } } synapse 0x...001 -> 0x...002 delay 50.0 mode simulate }
